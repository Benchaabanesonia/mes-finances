Publication : créer un dépôt GitHub PUBLIC, téléverser les fichiers de ce dossier à la racine, Settings > Pages > Deploy from a branch > main / (root) > Save. Attendre la publication. Sur Android ouvrir le lien HTTPS dans Chrome puis menu > Ajouter à l’écran d’accueil / Installer. Les données sont propres au navigateur et à l’origine web ; elles ne migrent pas automatiquement depuis la version fichier sur ordinateur. Sauvegarder le JSON et restaurer sur Android si nécessaire. GitHub Pages publie tous les fichiers du dépôt : ne jamais y ajouter des exports personnels.
