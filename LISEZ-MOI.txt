MES FINANCES — VERSION 3

1. Dans l'application Android actuelle, faites Réglages > Sauvegarde (.json).
2. Décompressez ce ZIP sur votre ordinateur.
3. Sur GitHub, ouvrez votre dépôt mes-finances, puis Add file > Upload files.
4. Glissez les 7 fichiers index.html, app.js, style.css, sw.js, manifest.webmanifest, icon-192.png, icon-512.png (pas le dossier).
5. Validez avec Commit changes. Les fichiers portant les mêmes noms seront remplacés.
6. Après publication, ouvrez l'adresse GitHub Pages en ligne et actualisez. Sur Android, fermez puis rouvrez l'application ; si nécessaire, relancez-la une fois en ligne.

Les données restent dans le stockage local du navigateur, tant que l'origine GitHub Pages et les données du site ne changent pas.

ANCIENNES DONNÉES : les opérations existantes sont préservées. Les anciens revenus « Maman (cash) » sont considérés comme espèces, les autres revenus et dépenses anciens comme opérations sur compte. Les prélèvements sur l'épargne restent suivis séparément dans Analyse.

Note : « Espèces disponibles » est calculé à partir des opérations enregistrées depuis le début du suivi. Pour représenter un montant d'espèces déjà possédé avant le suivi, ajouter une entrée d'espèces initiale.
